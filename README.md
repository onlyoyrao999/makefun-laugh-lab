A tiny Python program that prints one funny one-liner — the excuse a robot vacuum gives after eating a sock — and writes it to /output/entry.txt for make.fun's One-Liner Laugh Lab bounty.

## The line

> My programming says 'eat everything on the floor.' Nobody told me socks have feelings — or a matching pair waiting at home.

## Run it

```sh
python3 main.py
```
